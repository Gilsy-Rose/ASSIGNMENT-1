# ASSIGNMENT-1 DATA EXPLORATION
**"DATA EXPLORATION"-
This assignment focuses on basic Excel data analysis and commonly used Excel functions. The dataset contains product information such as Product ID, Price, and Quantity.

Topics Covered
SUM – Calculate total values
COUNT – Count the number of products
AVERAGE – Calculate average price
MIN – Find the minimum price
MAX – Find the maximum price
COUNTIF – Count products based on a specific condition
SUMIF – Calculate totals based on a condition
MID – Extract the month from the Product ID
